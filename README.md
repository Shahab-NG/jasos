# بازی جاسوس

`npm ci` وابستگی‌ها را نصب می‌کند. با `npm run dev` نسخهٔ توسعه را اجرا کنید. `npm run build` خروجی استاتیک را در `dist` می‌سازد. برای نصب و اجرای آفلاین، خروجی را روی HTTPS یا localhost سرو کنید و ابتدا یک بار آنلاین باز کنید.

هدر و فوتر در `src/components` هستند. تنظیمات، کارت‌ها، گفت‌وگو، رأی‌گیری و نتیجه در `src/games/spy/components` قرار دارند. کلمه‌ها در `src/games/spy/words.js` تعریف شده‌اند. برای اضافه کردن بازی جدید، یک پوشه در `src/games` بسازید و ورودی آن را در فهرست `games` در `src/main.jsx` اضافه کنید. شناسهٔ بازی در هش URL می‌آید.

بازی روی یک دستگاه انجام می‌شود. دور جاری، تنظیمات و کلمه‌های قبلی در localStorage همان مرورگر نگهداری می‌شوند.

برای ویندوز، فایل ZIP را در درایو `C:\` استخراج کنید تا پوشهٔ `C:\jasos` ساخته شود. در PowerShell وارد پوشه شوید و دستورهای زیر را اجرا کنید.

```powershell
cd C:\jasos
npm ci
npm run dev
```

## وضعیت فعلی پروژه

جاسوس یک وب‌اپ فارسی، راست‌چین و واکنش‌گرا با React 19، Vite 6 و Tailwind CSS 4 است. فونت وزیرمتن همراه برنامه نصب می‌شود. نسخهٔ فعلی پس‌زمینهٔ پاستلی یاسی، صورتی و نعنایی دارد و دکمه‌ها و کارت‌ها با سایه و لبهٔ برجسته طراحی شده‌اند.

- بازی برای ۳ تا ۲۰ نفر روی یک دستگاه طراحی شده است. بازیکنان گوشی را دست‌به‌دست می‌کنند و هر نفر کارت نقش خودش را می‌بیند و می‌پوشاند.
- تنظیمات شامل تعداد بازیکنان و جاسوس‌ها، نام‌ها، ترتیب تصادفی، تایمر خاموش یا ۵، ۱۰ و ۱۵ دقیقه و انتخاب دسته‌هاست.
- بانک بازی ۱۰۰۰ واژهٔ یکتا در ۱۴ دسته دارد. انتخاب «همه» کل بانک را وارد قرعه می‌کند. اگر دسته انتخاب شود، قرعه فقط از همان دسته‌هاست. واژه‌ها تا پایان واژه‌های تازهٔ مجموعهٔ انتخابی تکرار نمی‌شوند.
- پس از کارت‌ها، بازیکنان سرنخ می‌دهند و رأی‌گیری می‌کنند. اگر گروه همهٔ جاسوس‌ها را پیدا کند، بازیکن‌ها برنده می‌شوند. در غیر این صورت، جاسوس برنده می‌شود. نقش جاسوس در هر دور بین بازیکن‌ها می‌چرخد.
- تنظیمات، مرحلهٔ دور جاری و واژه‌های قبلی در `localStorage` با کلید `jasos.spy.v1` ذخیره می‌شوند. منطق بازی و بانک واژه‌ها در مرورگر اجرا می‌شوند.
- ساخت production و آزمون‌های منطق بازی، ذخیره‌سازی، انتخاب دسته و تکرار نشدن واژه‌ها قبلاً موفق بوده‌اند. نمایش نسخهٔ پاستلی روی موبایل و اجرای آفلاین در مرورگر تأیید نشده‌اند.

## نقشهٔ فایل‌ها

| مسیر | کاربرد |
| --- | --- |
| `src/main.jsx` | نقطهٔ ورود React، فهرست بازی‌ها و ثبت Service Worker در نسخهٔ production |
| `src/components/Header.jsx` و `src/components/Footer.jsx` | اجزای مشترک صفحه |
| `src/style.css` | Tailwind، رنگ‌های پاستلی و استایل کارت‌ها و کنترل‌ها |
| `src/games/spy/Spy.jsx` | وضعیت بازی و جابه‌جایی بین مراحل |
| `src/games/spy/model.js` | قرعهٔ نقش و واژه، مقایسهٔ حدس و ذخیره‌سازی |
| `src/games/spy/words.js` | فهرست دسته‌ها و واژه‌ها |
| `src/games/spy/components/` | تنظیمات، راهنما، کارت نقش، گفت‌وگو، رأی‌گیری و نتیجه |
| `public/app.webmanifest` و `scripts/offline.mjs` | مشخصات نصب و تولید Service Worker |

## ادامهٔ کار در Codex

این README وضعیت فعلی را توضیح می‌دهد. دستور بعدی کاربر مشخص می‌کند چه تغییری باید انجام شود. پیش از ویرایش، فایل‌های مرتبط با همان دستور را در پروژهٔ بازشده بررسی کن. تغییرات هر بازی را در پوشهٔ خودش نگه دار و برای تغییرات ذخیره‌سازی، امکان ادامهٔ بازی‌های قبلی را در نظر بگیر. بعد از تغییر کد، `npm run build` را اجرا کن. اگر تغییر روی رابط کاربری اثر دارد و مرورگر در دسترس است، همان مسیر را در عرض موبایل هم بررسی کن.
